# Remaining evidence requirements

All six profile choice groups have a deterministic decision or an explicit WAIT
path. There are no remaining blocking **profile-choice** questions. Exact original
source identification remains NOT_IDENTIFIABLE, as recorded in frozen v1.

There is no unique source-provided automatic algorithm for meaningful liquidity,
reasonable EQH/EQL tilt, smooth structural approach, whole impulse, range clarity
or protected structural endpoints. The v1.1 implementation accepts explicit causal
source-validated evidence for these concepts. If evidence is absent, ambiguous,
incomplete or not yet known, it waits. This is not permission to create implicit
numeric classifiers, reuse old 751 flags, delete losses, or set every fact to true.

An automatic real-history run would require a source-faithful causal evidence
adapter or reviewed causal annotations with stable physical-context/POI IDs. The
adapter must attest the complete known contextual POI/liquidity inventory, correct
branch direction rules, unique source-defining stop geometry, and the computed
stop's clearance from known liquidity. Synthetic LONG/SHORT fixtures do not meet
this historical-evidence requirement.

M15 SFP/confirmed OB cannot use a strictly lower TF in the M15/H1/H4/D1-only profile.
They wait instead of enabling M1/M5 or changing source permissions. Missing ATR
history or historical public tick metadata also waits. Unordered simultaneous
OHLC touches cannot establish a fill/SL/FTA sequence and yield WAIT_INTRABAR_ORDER.

These limits are explicit conservative abstention paths, not resolved qualitative
detectors. They must be visible in any later coverage report. No first financial
backtest has been authorized for this stage.
