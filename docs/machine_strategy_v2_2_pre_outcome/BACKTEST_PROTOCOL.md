# Machine financial preregistration

Independent machine cases, not exact Original, no shared project risk/position management. Run only the exact committed FROZEN_CASES cohort; all IDs/data/code/geometry frozen before financial outcomes. H1/H4 formation, H1 decision, M15 execution, D1/H4 context. Orders available only from first M15 OPEN at/after decision CLOSE; expire after one H1 cycle. Same physical event/POI never creates duplicate orders. No post-outcome admission reclassification.

Primary accounting NORMALIZED_R_RESEARCH_MODE_UNROUNDED_THEORETICAL_PRICES: one risk unit per independently evaluated case; prices unrounded, explicit outward/inward relative epsilon 1e-8; no verified exchange tick/qty execution assertion. Gap improvement at observable OPEN is modeled with actual fill-to-fixed-stop price-risk denominator. No dummy tick or qty. Fixed initial stop and full nearest FTA / coincident Range 80/20; no BE. SFP pattern body invalidation at native setup-TF CLOSE.

M15 is finest history. OPEN before extrema. Both SL/FTA in one M15 bar -> WAIT_INTRABAR_ORDER. Wick limit+FTA in entry bar also unordered, regardless apparent outcome. Stop-only wick crossing is causally ordered under registered continuous within-bar path. Unresolved cases excluded from CLOSED primary sample and reported separately; exclusion may bias the resolved sample. No forced EOF liquidation: open filled/order cases censored. Fill and hold times use observed OPEN/completed candle timestamps and bounds.

Costs: entry and exit fee 6bps each; entry and exit proportional price slippage 2bps each, modeled as separate debits. Funding unsupported and excluded, never silently zero; Net is ex-funding. All monetary quantities are risk units, not actual exchange account currency. Counterfactual cost diagnostics 0.5x/1x/2x preset; no selection of strategy on best multiplier.

Closed-case diagnostic equity curve: initial 100 R units, constant 1 R per case, sorted exit time/case ID, no compounding. Drawdown is not simultaneous live portfolio drawdown. Report all metrics, branches/TFs/symbol/direction/year/month, unresolved and censored. Robustness gates from design READINESS_POLICY precede results. Dataset repeated-version retests are development results, not independent holdout validation.

No LIVE/private APIs. trade_entry_allowed=false.
