# Machine decision tree

Completed H1 cutoff -> advance only completed D1/H4/H1/M15 prefixes -> known swings -> body BOS -> confirming new endpoint -> selected impulse/protected origin -> known H1/H4/D1 context -> raw H1/H4 branch formation -> required next OPEN/reaction/retest -> M15 BOS+CONF -> origin-bound new POI or original branch entry POI -> unconsumed first-eligible state -> unique fixed stop -> complete causal liquidity/FTA inventory -> valid forward target -> deterministic physical/branch/POI dedup -> ALLOWED_MACHINE_SETUP -> next-cycle theoretical order.

Absent context/confirmation/POI/FTA = named WAIT until fixed expiry; invalid geometry/adverse liquidity/consumed or duplicate = reject. No source discretionary UNKNOWN is silently converted to source PASS. No order for M15/D1 standalone setup. Stage 1 Gate passes only if all machine definitions are complete; observational WAIT does not mean an undefined definition.
