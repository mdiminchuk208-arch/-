# Context model

Normative rules M2_SWING, M2_BOS, M2_CONF, M2_CONTEXT, M2_IMPULSE, M2_PD_OTE and M2_HTF. A BOS here is a machine break of the latest known reference, not a claim that arbitrary raw reference is Original protected structure. The origin becomes protected only after causal endpoint CONF. Endpoint updates occur on confirmation; body invalidation retires context. Latest confirmed BOS selects a single impulse; stable IDs resolve equal-time ambiguity.
