# Branch contracts

SFP: completed H1/H4 raid/reclaim -> native next OPEN reclaimed -> M15 BOS/CONF -> new origin-bound M15 OB/FVG -> fixed pattern ATR stop -> nearest causal FTA.

OB: raw source raid/engulf geometry -> later reaction -> M15 BOS/CONF -> new origin-bound POI -> source extreme stop -> FTA.

Breaker: machine-contextual parent OB -> opposite body break -> M15 BOS/CONF without opposite BOS -> body-zone retest limit -> whole parent-to-break extreme stop -> FTA.

STB/BTS: raw manipulation/engulf -> H1 context and M15 BOS/CONF -> manipulation body midpoint -> manipulation extreme stop -> FTA.

Range: confirmed impulse plus interior correction -> EQ reaction -> first deviation/reclaim -> later boundary retest -> M15 BOS/CONF -> boundary limit -> deviation stop -> nearest FTA/far-boundary cap, coincident 80/20 exit.

M2_BRANCH_PRIORITY selects a single machine physical event sibling; rejected siblings retained. Definitions and citations are in registry M2_OB/M2_SFP/M2_STB/M2_BREAKER/M2_RANGE/M2_SMOOTH.
