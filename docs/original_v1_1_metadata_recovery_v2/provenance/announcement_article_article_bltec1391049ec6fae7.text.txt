Note
:
For trading pairs where the tick size is adjusted to a higher decimal value, such as from 0.0001 to 0.001, the adjustment may result in negative grid profits for the respective Futures Grid Bot. This change may also lead to Futures Martingale liquidation in extreme cases. Hence, you are advised to manually terminate your bot before the adjustment to avoid any potential loss, and you can create a new bot after the adjustment is completed. Please note that this applies to bots created through Copy Trading as well.
Changes to the tick size will not impact any trading functions for USDT Perpetual Contracts.
API users can access updated tick sizes via GET /v5/market/instruments-info after the mentioned timestamp. For more details, please consult our API 
documentation
.
Orders placed before the specified timestamp will remain in the order book with the original tick size, but will be displayed with the new tick size.

If necessary, please align your trading strategy based on the updated tick size. We appreciate your understanding for any inconvenience this may cause.
