The frozen SOURCE framing and the visible histories permit exact conditional facts but do not supply
an unambiguous contextual/protected-object selector. This reviewer records that missing relationship
for every question with its actual view binding. A geometry-valid primitive is not promoted into a
contextual witness. Existing UNKNOWN labels and absence of external annotations are not themselves
used as the reason for a new annotation.

This is a deterministic source-evidence sufficiency review. It does not certify that a qualified
human could never select a plausible discretionary context, and it does not claim exhaustive human
visual review of every chart. Human discretionary witnesses would need a new frozen version; where
multiple materially valid contexts remain and source provides no priority, uniqueness must remain
unresolved. No inference from old strategy results is permitted.
