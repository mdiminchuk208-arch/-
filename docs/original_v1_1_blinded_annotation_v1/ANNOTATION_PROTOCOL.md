# Blinded source annotation v1 — pre-label protocol

Parent v3 is immutable, manifest 2ac66c22e51ca21cfa802002a98fdc52d60c1d16c57899cfb2d3aaaf7365055e.
All 131099 v3 qualitative candidates are processed in chronological batches of 100 (transport only).
The last batch is smaller. Each candidate retains its own cutoff: a batch maximum is never its view.
Source citations are the frozen SOURCE_RULE definitions/primary passages, not U choices or project policy.

The annotator is a deterministic SOURCE_INPUT_SUFFICIENCY_REVIEW, not a claimed human chart review.
It materializes exact candidate relations and all four causal prefix descriptors, advances archived
objects/candles only up to the candidate cutoff, validates visible-object identities and source framing,
and asks whether each source predicate is actually identifiable from this view. It does not classify
smoothness/range clarity/order flow with a substitute numeric/visual heuristic. No discretionary label
is generated solely because an existing v3 label was UNKNOWN or because an external annotator is absent.

PASS/FAIL require a direct source implication or an already source-validated contextual witness with
its actual selected endpoints/POIs/roles. Raw geometry can be a conditional fact; it cannot establish
protected importance or choose a source context/impulse/range. If the source does not uniquely select
these material objects and the visible relations do not establish them, the answer is UNKNOWN with a
question-specific reason and explicit causal inventory. Missing proof is not FAIL. Labels remain
UNKNOWN rather than introducing a new protected-point/context/impulse selector. No claim that all
possible human discretionary interpretations have been reviewed or mathematically excluded.

A complete prefix is an immutable set represented by a verified count and content-derived rolling
hash; batch files include its exact relevant object records. This avoids copying multi-year candles
131099 times. The reader makes the full known prefix available, never later objects, and validates
completed-candle counts and timestamps. Full views can be rendered through the unchanged v3
materializer, whose prefix hash and cutoff are mandatory. Compact views are not cropped trading windows.

Every ledger record has candidate ID, question, answer, source citation references, cutoff, evidence
known_at, reason/UNKNOWN reason, annotator provenance and immutable view binding. Citation registry stores
full primary literal passages/file/page/hash. known_at is the time of the historical evidence available
to the view, not a claim that this retrospective research annotation was published in that year.
The annotations are generated now after a pre-label protocol, with no outcome inputs.

Forbidden: future candles/prices, outcomes, old labels, fitted rules, numeric thresholds, scores, ML,
P&L/MFE/MAE/duration-based labels. All output is evidence only, no executable ALLOW. trade_entry_allowed=false.
A future discretionary review would require a new immutable annotation version with explicit witnesses;
this freeze will not be edited in place. UNKNOWN counts are reported honestly, without claimed completion.
