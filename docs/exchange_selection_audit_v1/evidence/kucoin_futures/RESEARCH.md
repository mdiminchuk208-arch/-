# KuCoin Futures: public evidence, 2026-10-13 UTC

Raw bytes, request times, HTTP status, filtered headers, and SHA-256 are in `SOURCE_INDEX.json`. All probes used the inherited cloud HTTPS proxy and normal TLS verification. Failed or empty responses remain in the source index.

The live USDT-settled perpetual products are `XBTUSDTM` and `ETHUSDTM`, with BTC/ETH base units, `isInverse=false`, and multipliers `0.001 BTC` and `0.01 ETH` per lot. Current ticks are `0.1` and `0.01` USDT; lots are integral. The official symbol documentation describes `multiplier`: “The basic unit of the contract API is lots. For the number of coins in each lot, please refer to the param multiplier.” `kc_docs_contract_en`, `kc_btc_contract`, `kc_eth_contract`. Both order books were captured twice, at distinct exchange timestamps; `FACTS.json` multiplies each price level's contract count by the corresponding official multiplier to report base quantity. `kc_docs_fullbook`, `kc_*_book_1/2`.

The public instrument responses and example in the official API docs show `makerFeeRate=0.0002`, `takerFeeRate=0.0006` on both products. The official private futures actual-fee documentation says, “This interface is for the trading pair’s actual futures fee rate”; account tier or rebate differences remain unverified. These are published ordinary instrument quotes, with no assumed promotion. `kc_btc_contract`, `kc_eth_contract`, `kc_docs_contract_en`, `kc_docs_actual_fee_futures`.

Native 15-minute bars for both current products were retrieved with millisecond `from` and `to`. The same endpoint returned `code=200000, data=[]` for both around `2024-10-13T00:00Z`; that HTTP 200 does not prove historical depth. The docs permit time paging up to 500 bars and warn that intervals without ticks are absent. Funding history *did* return old 2024 records for both with mandatory `from/to`, but cannot substitute for old candles. `kc_docs_klines_en`, `kc_*_m15_now_ms`, `kc_*_m15_old_ms`, `kc_docs_funding_history`, `kc_*_funding_old`. Current OI appears in the symbol response; the official UTA historical OI docs state intraday retention of 7 days and daily 70 days, with compatibility of this newer endpoint to classic contracts unverified. `kc_docs_open_interest`.

The official REST docs show isolated margin switching, leverage in order parameters, reduce-only, client order ID, and separate exchange-side TP/SL. Futures order docs require `api-permission: Futures`; withdrawal docs separately require `api-permission: Withdrawal`, so a key can be scoped to futures trading without withdrawal permission. Per-endpoint rate weights and a public service-status endpoint are documented; the status request returned `open`. `kc_docs_switch_margin`, `kc_docs_add_order`, `kc_docs_add_tpsl`, `kc_docs_withdraw`, `kc_docs_status`, `kc_status`. IP binding was not verified in retained sources. No authenticated API call or order was made.

Research hard blocker: two-year-old native BTC/ETH M15 retrieval or an official archive remains absent. Execution uncertainties: actual account fee and IP binding. Current filter snapshots support prospective capture only; they do not reconstruct historical tick epochs.
