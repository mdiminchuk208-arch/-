# Exchange selection evidence protocol

Freeze SCORING_PREREGISTRATION.json in Git before collecting venue results. Fixed
user weights and binary anchored indicators; missing=zero with no reweighting.
Hard exclusions override ranks. Base/API fees only, signed exact decimals; promotions
are separately labeled. Funding is not a trading fee. Snapshots use all retained
valid observations, exact contract units and equal preregistered sizes/symbols.
Two separated samples are a limited contemporaneous diagnostic, not an execution
guarantee. No outcome-based strategy change or financial strategy run.

Official public GET endpoints, and Hyperliquid public POST /info only. No private
API, credentials, cookies, accounts, orders, VPN or alternative geographic routing.
The cloud requires its inherited session egress transport; preserve proxy/CA/TLS
as mandated by cloud runtime. It is not a new proxy/geoblock evasion route. Actual
403/451 are retained and never bypassed. GitHub CI runs ordinary hosted Ubuntu,
without exchange secrets and without custom routing. Record each environment.

Each source retains raw bytes, request/retrieval UTC, latency, status and filtered
headers with SHA256; distinguish docs claims, actual response identity, observed
depth and unknown history continuity. Retain fee citations literally. No claims
from memory. Endpoint success alone is not contract or history proof.
