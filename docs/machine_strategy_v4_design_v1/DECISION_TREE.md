# MACHINE_STRATEGY_v4 deterministic decision tree

Normative nodes are DECISION_TREE.json and the two versioned ENTRY_EXIT/EXECUTION contracts. Missing evidence waits or stops unresolved; it is not structural failure. No outcome column enters any admission node.

```mermaid
flowchart TD
  A[Completed contiguous causal prefix] --> B[H1/H4 formation and inherited reaction]
  B --> C[Known native structural invalidation?]
  C -->|yes| R[Retire observed invalid idea]
  C -->|no| D[Selected M15 CONF fresh through decision]
  D -->|missing / dual / later opposite| W[WAIT with stable origin ID]
  D -->|clean or corrective| E[Inherited H1 / H4 / D1 context and origin-bound POI]
  E --> F[Reference rounded entry / nearest raw FTA]
  F -->|completed FTA| R
  F --> G[One-grid selected POI envelope; structural stop; inward target]
  G --> H[Doubled-cost planned target >= base-cost planned stop unit]
  H -->|fail| X[Reject payoff; no farther FTA]
  H -->|pass| I[Common reference case and exclusive reservation]
  I --> J[All nine stress plans; retain every disagreement]
  J --> K[Pending structural lifecycle before next OPEN]
  K --> L[Inherited contact / gap / OHLC ambiguity]
  L -->|filled| M[Inherited stop / nearest target / SFP native body exit]
```

At every native M15 interval, execution uses the snapshot known at OPEN; CLOSE/POI changes observed at end apply prospectively to remaining pending orders. H1 is the only new-signal decision clock. Context/POI lifecycle does not create a new exit for filled positions. Deadline is original formation_known_at+57600, executable interval half-open.

Planned payoff ratio N2_s/K_s and eventual financial reporting cash/U are distinct. No actual historical v4 case is evaluated by this document or its synthetic tests.
