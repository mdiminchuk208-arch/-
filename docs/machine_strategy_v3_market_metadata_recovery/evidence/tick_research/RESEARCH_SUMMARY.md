# Public historical tick metadata research

Scope: Bybit USDT linear perpetual BTCUSDT and ETHUSDT, `2022-01-01T00:00:00Z <= t < 2025-12-05T23:30:00Z`. This work read no strategy outcome data and ran no trading or financial evaluation. Every new raw response and receipt is in this directory. `SEARCH_INVENTORY.json` indexes 82 captured HTTP responses; `SOURCE_CANDIDATES.json` gives the eight strongest candidates with separate title, claimed publication, claimed effective, archive capture, Git commit and retrieval times. `build_research_inventory.py` verifies each retained byte hash and rebuilds both inventories.

## Findings

* **ETH official notice:** The independent Arquivo.pt capture of `2023-02-05T04:10:38Z` preserves an official page naming `ETHUSDT` *USDT Perpetual* and a claimed `0.05 -> 0.01` change effective `2023-01-17T08:00:00Z`. The archived page's Open Graph `article:published_time` advertises `2023-01-06T07:03:06Z`, but the archive capture is after the claimed effective time. Its earliest independently established existence in this research remains the archive capture. The old frozen copy was copied byte-for-byte, verified against SHA-256 `43823daf528216e1cc4f55b511b1ea1e68d955820b95af95882fff292314c9a9`, and its original retrieval/capture times remain distinct in `archived_eth_20230205.receipt.json`.
* **BTC official notice:** The current official page names `BTCUSDT` *USDT Perpetual* and a claimed `0.5 -> 0.1` change effective `2023-02-10T08:00:00Z`. Its title says 2023-02-08; Open Graph `article:published_time` says `2023-02-07T11:02:47Z`. Those are page assertions in a 2026 retrieval, not an independent pre-effective capture. No contemporary BTC capture was obtained.
* **CCXT immutable fixtures:** The GitHub repository history for `ts/src/test/static/markets/bybit.json` has a 2023-10-28 commit with exact `BTCUSDT`, `LinearPerpetual`, `settleCoin=USDT`, `priceFilter.tickSize=0.10`; a 2023-10-31 commit also has `ETHUSDT` with `tickSize=0.01`. The same fixture fields remain in inspected 2024-03-26 and 2025-05-19 commits. All four raw files and commit-history response are retained. Git author/committer dates are repository metadata; the underlying exchange response capture time is absent. Carried-forward fixture values are not fresh independent snapshots. They corroborate the later settings' representation but do not prove exchange-effective boundaries or continuity.
* **Tardis instrument metadata:** Its public documentation states that `priceIncrement` is sourced from exchange metadata and that `changes[].priceIncrement` can record historical values. The same documentation says only `contractMultiplier` changes are guaranteed complete; `priceIncrement` changes are tracked on a best-effort basis. Public unauthenticated BTCUSDT and ETHUSDT instrument calls both returned HTTP 401 with a pro/business subscription requirement. No symbol values were obtained. Even a paid response would require independent completeness and time validation.
* **Rejected Hummingbot fixture lead:** Retained 2022 and 2023 Bybit perpetual test files contain a synthetic `price_filter.tick_size=0.5` for a parameterized pair. The 2023-02-22 commit still carries that value after the BTC notice's claimed 2023-02-10 change. The fixture has neither a dated exchange capture nor reliable exact BTCUSDT identity; it is not an epoch source. This illustrates why repository test data cannot be read as live snapshots merely from commit dates.

The literal official notices describe exchange tick-size changes, and CCXT's `priceFilter.tickSize` field is instrument metadata rather than display precision. None of the found sources establishes complete nonoverlapping BTC/ETH executable epochs over the target interval. No epoch is promoted from this research. The strongest gap remains independently timed exchange state before the 2023 changes, plus proof of the actual changes and continuous state through the 2025 end.

## Bounded search matrix and limits

| Class | Retained probes | Result and limit |
| --- | --- | --- |
| Official index discovery | DuckDuckGo and Brave queries by exact symbol, tick-size wording and years 2022–2025; 2022-12-29, 2023-04-10/11-01/12-15/12-22, 2024-04-03, 2025-02-11/05-21 official pages | Retrieved page bodies did not name exact BTCUSDT or ETHUSDT, except the two known Jan/Feb 2023 notices. A substring such as `NEIROETHUSDT` is not the ETHUSDT contract. Index silence is not evidence of no changes. Several search responses were HTTP 202/429 throttles. |
| Public archives | Internet Archive exact and Contentstack-ID wildcard CDX queries; Arquivo.pt exact and wildcard queries for BTC/ETH notices and instrument API URLs; selected Common Crawl 2023 indexes | No earlier independent capture was recovered. Several probes returned empty indexes, timeout, 404/502/504 or an archive temporary-offline page. A miss cannot establish absence. The independently archived ETH copy from the frozen gate remains the strongest capture. |
| Third-party instrument archives | Tardis Instruments Metadata API documentation and two unauthenticated exact-symbol calls; CCXT static market fixture GitHub directory, commit-history API, four immutable commit files | Tardis values gated and change completeness disclaimed. CCXT has exact instrument fields but no exchange capture time or update cadence guarantee. |
| Other third-party metadata lead | Hummingbot Bybit perpetual test fixture GitHub history, 2022/2023/2024 revisions | Synthetic and demonstrably carried forward; rejected for epoch proof. |

The query boundary is the retained response set and named public services, not a claim that all possible archives or paid datasets have been searched. Search failures and inaccessible subscription data remain unknowns. The appropriate gate outcome from this research alone is `UNVERIFIED`, with zero new verified historical epochs.
