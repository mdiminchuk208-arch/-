# Autonomous Objective

Produce a statistically credible Crypto Bot production candidate without rewriting frozen research or manufacturing profitability.

Execution order:
1. Failure audit of v2/v2.1/v2.2.
2. Diagnose signal-quality vs entry/stop/target/cost/regime failure mechanisms.
3. Design Machine Strategy v3 only after diagnosis.
4. Freeze v3 before P&L.
5. Backtest v3 deterministically.
6. Run robustness and independent OOS/forward validation.
7. Iterate to later versions only with explicit causal rationale and new pre-outcome freezes.
8. Test project overlays only after a qualified base strategy exists.
9. Paper trading only after historical/OOS quality gates pass.
10. Real trading only after successful paper qualification and explicit user authorization.

Never optimize for a pretty backtest. Optimize the research process for truth, reproducibility, and durable edge.
